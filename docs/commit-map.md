# Відповідність хешів збірок у логах і комітів

У першому рядку логів у `docs/metrics/` стоїть хеш збірки (`git=...`). Після виправлення авторства комітів перед тегом `lab3` хеші змінились. Логи ми не правили: вони лишились зі старими хешами збірок. Таблиця зв'язує їх з поточними комітами.

| Хеш у логу (`git=`) | Поточний коміт |
|---|---|
| `f4751f7` | `af447e2` |
| `9783028` | `e5474f7` |
| `7622841` | `6adffb2` |
| `a5c03e3` | `9a37eb6` |
